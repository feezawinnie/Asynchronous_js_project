# Asynchronous JavaScript Project

This repository is a learning space for **asynchronous JavaScript**.

The project is a small vanilla JavaScript application used to practice:

- XMLHttpRequest
- Promises
- the Fetch API
- async/await
- Promise combinators (`all`, `race`, `allSettled`, `any`)
- the event loop
- error handling

The app runs in the browser with HTML, ES modules, and Tailwind CSS. No JavaScript frameworks.

## Project code

The full project lives on the `ft/project_async` branch:
