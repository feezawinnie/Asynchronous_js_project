Promise Combinators

Each combinator solves a different concurrency problem.

Promise.all() — fail-fast

4 requests: 3 succeed, 1 fails → entire batch rejects.

—

Promise.allSettled() — partial failure

Same 4 requests — all finish, extract successes & failures.

—

Promise.race() — first to settle

API request vs 3-second timeout.

—

Promise.any() — first success

3 failing sources + 1 success → only success matters.

—
